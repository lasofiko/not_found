# Состав интерфейса

`src/App.tsx` — выбор и отображение синтетических примеров.
`src/demo-fixtures.json` — готовые вымышленные числа без источника наблюдений.
`src/ForecastCharts.tsx` — графики с единицами; `src/App.css` — темы и адаптация.
`src/components/ui` — компоненты интерфейса.
Сборка и запуск описаны в `README.md` этой папки.
