# FloCast — основной Frontend

Утверждённый интерфейс — существующий React с контейнеровозом, светлой серо-сиреневой
темой, фиолетовыми кнопками, Sidebar, «Системой в цифрах» и AI-панелью.
Точка входа: frontend/index.html → src/main.tsx → src/App.tsx.
Основные стили App.css и index.css, шрифты и фотографии сохранены.

## Разработка

Нужны Node ^22.12.0 либо >=24 и Python 3.11+. Из корня проекта:

    npm --prefix frontend ci
    npm --prefix frontend run dev

Открыть http://127.0.0.1:5173/ . Если вы уже в папке frontend, команды короче:

    npm ci
    npm run dev

Во втором терминале из корня проекта, в активном Python-окружении:

    python -m uvicorn backend.app:app --reload

Vite работает на 127.0.0.1:5173, проксирует /config.json и API на backend:8000.
BB_DEV_BACKEND_URL и BB_API_PREFIX читаются из корневого .env/окружения.
После изменения этих настроек перезапустите Vite. Не закрывайте терминал dev:
сообщение ready не означает, что сервер продолжит работать после остановки процесса.

## Единый режим

    npm --prefix frontend run build
    python -m uvicorn backend.app:app --reload

Основной адрес http://127.0.0.1:8000/ непосредственно отдаёт этот же React,
без перехода адресной строки на /dashboard/. Старые /dashboard/ перенаправляются
на корень, /capacity и /capacity.html — на /#capacity. В Vite действует та же схема.

CapacityCalculator.tsx встроен в существующую страницу и обращается к прежнему
POST /api/v1/scenarios/capacity. Все пять результатов, период, источник и
предупреждение приходят от backend. Во фронтенде арифметика не дублируется.
Редактирование отменяет запрос и очищает результат. Повторный запрос блокируется
во время ожидания; после ошибки доступен повтор.

build-info.ts сохраняет SHA-256 исходников, public, конфигурации и index.html.
Backend сверяет dist/build-info.json с текущим frontend. Без сборки или при
устаревшем dist он возвращает 503 с командой build; API продолжает работать.
После сборки перезапуск для её обнаружения не нужен. Для этой проверки
сохраняйте src/public/конфигурацию frontend рядом с dist при запуске из репозитория.
HTML исключён из PWA precache. После обновления старой версии полезен Ctrl+Shift+R.

Старые capacity.html и app.js сохранены как исходная реализация, но HTML не
раздаётся как отдельный пользовательский интерфейс FastAPI.

## Интеграции

- Годовой прогноз получает реальные ответы GET /forecasts. Поддержана морская линия Усть-Луга — Балтийск, inbound/outbound, годы 2024–2030, тонны за год.
- При отсутствии модели показывается not_connected; числа не подставляются. На проверенном Windows-компьютере модель bb-ml-6237c3f27262 доступна.
- Таблица, графики и CSV используют один проверенный ответ API с источниками и версиями.
- Существующее демо отделено и маркируется synthetic. Другим регионам и городам не присваиваются его числа.
- Географический справочник и четыре транспортные фотокарточки сохранены. Для Приморья, Камчатки, rail_land/road/air прогнозные модели к API пока не подключены.
- Реестр действий загружается GET /scenarios; калькулятор показывает чувствительность к вводу, а не подтверждённый эффект инвестиции.
- AI-панель использует серверные GET /llm/summary и POST /llm/ask. Ключей в браузере нет. Без BB_LLM_* выводится LLM_NOT_CONFIGURED. Есть таймауты и повторное подключение конфигурации.
- Карта OpenStreetMap сохранена; нужны интернет и поддержка браузера.
