# FloCast — Frontend

React + TypeScript + Vite. Нужен Node 22.12+ или 24 и npm.

Из корня проекта:

```powershell
npm --prefix frontend ci --ignore-scripts
npm --prefix frontend run lint
npm --prefix frontend test
npm --prefix frontend run build
```

Затем запустите или перезапустите backend по корневому README.
Демо: http://127.0.0.1:8000/dashboard/.
Калькулятор мощности: http://127.0.0.1:8000/capacity.
Без сборки демо возвращает 503; API и калькулятор продолжают работать.

Разработка: `npm --prefix frontend run dev`, откройте
http://localhost:5173/dashboard/. Предпросмотр готовой сборки:
`npm --prefix frontend run preview`, URL выводится в терминале.
Для отдельного калькулятора отредактируйте `config.json` и настройте CORS
по корневому README; это не настройки React-демо.

Действующий экран получает годовой прогноз линии Усть-Луга — Балтийск через
`GET /api/v1/forecasts`. Выбираются направление и конечный год 2024–2030.
Графики и CSV содержат значения ответа API, единицы, источники и версии.
При отсутствии модели отображается сообщение без подстановки примеров.
Синтетические `src/demo-fixtures.json` используются прежними тестами.

Действия А и Б загружаются из реестра backend, их доступность показана явно.
Калькулятор мощности открывается по `/capacity` и считает чувствительность
по пользовательскому вводу. Он работает отдельно от модели.
Панель Yandex AI Studio подключается по запросу и показывает отказ сервиса.

Подробности модели и установки описаны в [инструкции интеграции](../docs/ml-integration.md).
