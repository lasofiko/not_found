# FloCast — Frontend

React + TypeScript + Vite. Нужен Node 22.12+ или 24 и npm.

Из корня проекта:

```powershell
npm --prefix frontend ci --ignore-scripts
npm --prefix frontend run lint
npm --prefix frontend test
npm --prefix frontend run build
```

Затем запустите Backend по корневому README.
Единый интерфейс: http://127.0.0.1:8000/.
Встроенный калькулятор: http://127.0.0.1:8000/#capacity.
Старые /dashboard/ и /capacity перенаправляют в тот же React.
Без актуальной сборки UI возвращает 503; API продолжает работать.
После изменения src, public или настроек повторите build и обновите страницу.
Перезапуск Backend после пересборки не требуется: SHA-256 проверяются при раздаче.

Разработка: отдельно запустите Backend на 8000, затем
`npm --prefix frontend run dev -- --host 127.0.0.1`, откройте
http://127.0.0.1:5173/. Vite проксирует /config.json и API.
BB_API_PREFIX и BB_DEV_API_TARGET читаются из корневого .env и окружения.
После изменения настроек перезапустите оба процесса. Service worker старого
production-приложения снимается в dev, чтобы не скрывать актуальные исходники.

Все числа `src/demo-fixtures.json` вымышлены (`synthetic`), включая 2025 год.
Они сохранены только для регрессионных тестов и не используются в React-экране.
React получает реальный годовой прогноз и реестр действий из API. При отсутствии
модели показывает ошибку без подстановки чисел. CSV и графики используют один ответ
API с единицами, источниками и версиями. Калькулятор вызывает существующий
POST /scenarios/capacity по пользовательскому вводу, отдельно от прогноза.
Панель AI-ассистента использует внешний виджет Yandex AI Studio из нового дизайна.

проверить удобство интерфейса и отдельно принять предметные данные и действия.
