# FloCast — Frontend

React + TypeScript + Vite. Нужен Node 22.12+ или 24 и npm.

Из корня проекта:

```powershell
npm --prefix frontend ci --ignore-scripts
npm --prefix frontend run lint
npm --prefix frontend test
npm --prefix frontend run build
```

Затем запустите или перезапустите backend по корневому README.
Демо: http://127.0.0.1:8000/dashboard/.
Калькулятор мощности: http://127.0.0.1:8000/capacity.
Без сборки демо возвращает 503; API и калькулятор продолжают работать.

Разработка: `npm --prefix frontend run dev`, откройте
http://localhost:5173/dashboard/. Предпросмотр готовой сборки:
`npm --prefix frontend run preview`, URL выводится в терминале.
Для отдельного калькулятора отредактируйте `config.json` и настройте CORS
по корневому README; это не настройки React-демо.

Все числа `src/demo-fixtures.json` вымышлены (`synthetic`), включая 2025 год.

Географический выбор расширен до трёх исследуемых регионов с уточнением
отправления и доставки по региону/городу. Справочник работает локально,
доступен ручной ввод отсутствующего города. Для неподключённой детализации
числа не показываются. Поля, покрытие, источник, лицензия и воспроизведение:
[GEOGRAPHY.md](GEOGRAPHY.md). Проверка: `npm --prefix frontend test` из корня.
Это проверка отображения, а не наблюдения, прогноз или эффект инвестиции.
Выбираются направление коридора и один из трёх готовых примеров для моря.
Параметры действий командой не утверждены. Расчёт чувствительности по вводу
пользователя остаётся в backend и доступен через калькулятор мощности.
CSV экспортирует выбранный пример со статусом, происхождением и единицами.
Панель AI-ассистента подключена к основному backend (`/api/v1/llm/summary` и
`/api/v1/llm/ask`). Она использует тот же `apiBase` из `/config.json`, что и
остальные запросы; внешний виджет Yandex AI Studio удалён. Frontend не хранит
LLM-ключей и не обращается к провайдеру напрямую. При открытии панели
автоматически запрашивается краткая сводка; пользователь может задать вопрос
или запросить сводку повторно.

Для перехода к калькулятору из Vite одновременно запустите backend на
`http://127.0.0.1:8000`. Vite перенаправляет `/capacity`, `/app.js`, `/config.json`
и запросы API к backend. Другой адрес задаётся `BB_DEV_BACKEND_URL` в корневом
`.env` или окружении; `BB_API_PREFIX` читается там же. После изменения этих
настроек перезапустите Vite. Без backend React-демо работает самостоятельно,
а калькулятору нужен доступный API.

Калькулятор отменяет текущий запрос и очищает результат при редактировании
формы, блокирует повторную отправку и ограничивает ожидание 15 секундами.
Панель ассистента открывается кнопкой, автоматически запрашивает сводку,
блокирует повторную отправку во время запроса, восстанавливает текст вопроса
при ошибке и показывает сообщение об ошибке backend. Клик по фону вне окна
закрывает панель, как Escape и кнопка закрытия.

## Обновлённое оформление

Собственная панель ассистента использует общую фиолетово-бирюзовую палитру
приложения, отдельно для светлой и тёмной тем.
Клик по фону вне окна закрывает чат, как Escape и кнопка закрытия.
Проверка оформления не отправляет сообщения и не очищает переписку.

Края фотографий первого экрана и блока ассистента плавно растворяются в фоне.
Фильтры используют округлённые списки в цветах активной темы с управлением
клавиатурой; кнопка смены направления выделена рамкой и не содержит стрелки.

Если браузер показывает предыдущую сборку, нажмите Ctrl+Shift+R или один раз
откройте `/dashboard/?updated=20261110-labels`. HTML и файлы обновления PWA
теперь раздаются с `Cache-Control: no-store`, навигация PWA обходит HTTP-кэш.
После изменения backend перезапустите его; `--reload` делает это автоматически.

По пользовательским скриншотам удалены декоративные номера и разделители
разделов/карточек, повторяющиеся пояснения, подпись первого экрана и контекст
под заголовком чата. Маркировки демо, единицы, экспорт и встроенная атрибуция
карты сохранены. Данные и вычисления не менялись; правки выполнены ИИ локально.

Структура страницы перенесена из предоставленного HTML-образца: первый экран,
показатели, аналитика, четыре фотокарточки транспорта, карта, прогнозный контур,
выбор сценарного примера и блок происхождения данных. Сохранена исходная
фиолетово-бирюзовая палитра светлой и тёмной тем. Ассистент открывается отдельной
кнопкой; описания транспорта и чат закрываются кнопкой или Escape.

Фотографии из `public/images/` предоставлены пользователем и включены в сборку.
Это иллюстрации, не доказательство географии перевозки; место съёмки не проверено.
Приложение не обращается к папке Downloads. Для карты OpenStreetMap и
LLM-ассистента нужен интернет. Карта показывает географию коридора, без нанесённых
транспортных маршрутов и объёмов. Числовые данные, экспорт CSV и API сохранены.

Проверка вручную: откройте `/dashboard/`, переключите тему, направление и каждый
из трёх примеров; убедитесь, что показатели и графики согласованы. Откройте четыре
фотокарточки и закройте их через Escape. Проверьте меню на ширине 390 пикселей,
отсутствие горизонтальной прокрутки и экспорт CSV. Чат проверяется без отправки
сообщений. Основные транспортные гипотезы остаются открытым решением команды.

ИИ подготовил локальную переработку макета и проверку кода. Человеческая
визуальная и предметная приёмка командой остаётся отдельным этапом.

## Проверка интерфейса 10 ноября 2026

ИИ проверил шесть сочетаний направления и примера, экспорт CSV с выбранным
направлением и статусом, калькулятор через Vite, валидацию периода, обе темы,
карточки и возврат клавиатурного фокуса. На ширинах 320 и 768 пикселей
устранено переполнение; подписи осей сравнения содержат единицы. Подсветка
навигации следует за прокруткой, выбранная тема сохраняется локально.
Шрифты и фотографии включены в precache готовой сборки; внешняя карта и
LLM-ассистент требуют сети. Графики выделены в отдельный загружаемый модуль.

Проверки: 7 тестов frontend (в том числе 4 регрессии запросов калькулятора),
46 тестов backend, ESLint, TypeScript и сборка Vite. Команды приведены выше;
если Windows запрещает временный каталог pytest, используйте доступный путь
с `--basetemp` и `-p no:cacheprovider`. Автоматическая и браузерная проверка ИИ
не заменяет человеческую приёмку данных и выбранных действий команды.

ИИ исправил интеграцию и подготовил автоматические проверки. Человек должен
проверить удобство интерфейса и отдельно принять предметные данные и действия.
