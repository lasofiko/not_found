# Прогнозный модуль

Здесь появятся baseline, обучение, временная проверка и сериализация модели после выбора проверенного целевого ряда. Не обучать на `estimated` или `synthetic` как на наблюдённой цели и не заявлять точность без отложенных периодов. Контракт результата описан в `docs/contracts.md`.
