# Проверка излома Петропавловска-Камчатского

Задание: `tz-misha-petropavlovsk-2026-11-10.md`. Это отдельная диагностика
источников, которая не пересобирает данные и не пересматривает результат модели.

```bash
python -m ml.audit_petropavlovsk
```

Команда проверяет SHA-256 зарегистрированных оригиналов за май–декабрь 2025
и декабрь 2024. Выпуски с годом после 2025 отклоняются до чтения таблицы.
Из оригиналов независимо проверяются контекст порта, строка итога, год,
заголовок колонки, каботаж и единица. Для июня–декабря сопоставляются
накопления, соседние источники и разности с текущим и сохранённым обучающим
рядом. Сумма операторов используется только как проверка баланса оригинала,
не как замена портового итога.

Региональная проверка читает только измерения и колонки 2024/2025 локального
оригинала ЕМИСС 39233 через зеркало НЦСЭД. Остальные годовые колонки не
извлекаются в наблюдения. Прибытие, отправление и перевалка сохраняют разный
смысл; точного равенства между ними не требуется. Нативная выгрузка ведомства
не подменяется зеркалом без оговорки.

Выходы находятся в игнорируемом каталоге
`reports/generated/petropavlovsk-audit-2025/`:

- `sources.json`: происхождение, путь, SHA-256 и права оригиналов;
- `cell_checks.csv`: два источника, ячейки, накопления и формулы разностей;
- `cargo_differences.csv`: изменения групп без суммирования вложенных групп;
- `operators.csv`: присутствие операторов и их исходные ячейки;
- `regional_checks.csv`: отдельные региональные операции за 2024/2025;
- `summary.json`: машинные проверки и границы вывода;
- `audit_manifest.json`: хеши входов, кода и выходов диагностики.

Команда не загружает модели, результаты слепой проверки и исходные выпуски
2026; не вызывает обучение, `pipeline.verify` или пересборку. Полная
`pipeline.verify` включает повторную диагностику сентября, поэтому в рамках
этого мини-ТЗ используются проверки только разрешённых периодов.

Числовые производные SeaNews остаются локальными. Для жюри предназначено
[качественное заключение и локаторы](jury/petropavlovsk-audit.md). Машинная
сверка ИИ не является завершённой ручной сверкой Пети.
