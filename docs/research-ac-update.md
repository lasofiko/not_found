# Новые материалы A–C: учёт и ограничения

12 ноября 2026 года зарегистрирован предоставленный документ
«Открытые_данные_Усть_Луга_Балтийск_A_C.md». Исходный Markdown сохранён
неизменным по SHA-256; его 156 CSV-записей извлечены без изменения исходных полей.
Текущая версия указана в `data/processed/research_notes/latest.json`.

## Что добавлено

- `research_facts.csv`: все 156 записей, происхождение до строки Markdown,
  охват и ограничения. Идентификаторы включают хеш документа: новый C001
  не подменяет C001 прежнего блока C.
- `monthly_comparison.csv`: сравнение 69 значений за 23 месяца с ранее
  зарегистрированной таблицей Telegram. Сравниваются масса, вагоны и накатные
  единицы раздельно; исходные единицы сохраняются.
- `overlap_references.csv`: 8 совпадений по URL, периоду, числу и единице
  с прежними таблицами. Это ссылки для проверки, без автоматического слияния.
- `source_registry.json`, `source_references.csv`, `quality_report.json`,
  `manifest.json`, `README.md`: паспорт документа, первичные ссылки,
  результаты сопоставления и хеши.

Из 69 месячных значений 65 численно совпадают с прежней таблицей, для трёх
нет прежнего значения, для одного есть расхождение: **январь 2024, накатная
техника — 1 400 в новом документе против 1 500 в прежнем Telegram CSV**.
Обе записи сохранены; без сверки первичной публикации и сообщения число
не исправлялось. Численное совпадение также не подтверждает совпадение охвата,
округления или квалификаторов «более», «около», «порядка».

## Что меняется в исследовательских выводах

1. **Месячные итоги нельзя считать однородной линией четырёх паромов.**
   В 2024 году меняется флот. Январь–март 2025 имеют нерасшифрованный охват
   после смены маршрута «Антея»; апрель–май явно объединяют два маршрута.
   Во всех 15 значениях этих пяти месяцев стоит отдельная пометка охвата.
   Прежние записи Telegram не переписаны и требуют совместной сверки.
2. **Годовые цифры относятся к разным объектам.** В документе раздельно
   представлены три парома Росморпорта, терминальные комплексы и итоги
   оператора по двум линиям. Они не складываются и не заменяют направленный
   ряд 2015–2023. Подтверждения новой пригодной цели для обучения это не даёт.
3. **«2 млн т» имеет несколько смыслов.** Ожидаемый объём линии из выступления,
   автомобильная составляющая комплекса и прежняя оценка ж/д предела — разные
   утверждения с разными источниками. Исторические проектные 2,9/3,5 млн т
   и перспективные 4 млн т не устанавливают действующий предел ж/д участка.
   Выбор ограничения или его снятие остаётся решением команды. В коде
   `rail_part_limit` и прежних результатах ограничение пока сохранено;
   новые материалы не делают его подтверждённой действующей мощностью.
4. **Субсидии — вся программа.** Строки со ссылкой на заключение Счётной палаты
   дают отдельное основание для сверки исполнения 2024 года. Они не выделяют
   одну линию и не заменяют отсутствующие протоколы C029–C041 и снимок C050.
5. **Свидетельства ожидания относятся к указанному виду груза и периоду.**
   Ожидание автотранспорта нельзя переносить на очередь гружёных вагонов;
   выполненных рейсов, фактических стоянок и плана ремонтов 2027 по-прежнему нет.

## Уровень проверки

Исходное `verification=opened_source` сохранено как пометка автора.
Новая регистрация имеет `evidence_status=provided_unverified`,
`review_status=pending`. Первичные HTML/PDF новым импортом не скачивались;
их SHA-256 и локальный путь в реестре ссылок пусты.
При выборочной повторной проверке через веб-инструмент открылась страница
Росморпорта `/news/company/58571/`; Кремль и PDF Счётной палаты вернули тайм-аут,
страница Морского инженерного бюро — ошибку SQL. Прямая загрузка PDF из
локального окружения завершилась ошибкой DNS. Полная повторная сверка 156
значений не заявляется. B012 ссылается на «Транспорт России», а не на сайт
Минтранса; исходная атрибуция сохранена с дополнительным предупреждением.

Основные наблюдения, параметры сценариев, модели и слепые проверки не менялись.
Новых месяцев 2026 для обучения не добавлялось. ИИ выполнил регистрацию,
сопоставление и машинные проверки; новая человеческая приёмка не зафиксирована.

## Воспроизведение

```bash
python -m pipeline.research_notes --document 'Открытые_данные_Усть_Луга_Балтийск_A_C.md'
python -m pipeline.research_notes --verify
python -m pytest -q tests/test_research_package.py tests/test_current_snapshot.py
python -m ruff check pipeline/research_notes.py tests/test_research_package.py
python -m pipeline.current_snapshot
```

Первый шаг создаёт отдельную версию; повтор сохраняет паспорт и проверяет
существующие результаты. `--verify` повторно извлекает CSV из Markdown,
проверяет хеши и воспроизводит сравнения с закреплённой базовой регистрацией.
Общий архив обновляется отдельным снимком, прежние ZIP сохраняются.
