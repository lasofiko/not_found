# План синтетической генерации FloCast — 12.11.2026

## Этапы 1–2. Основание и пригодность

Источник — только три части `current-data-2026-11-12-8d7bea26dc98`.
Архивный код не исполняется, модели и прежние прогнозы не являются входами.
Полный файловый каталог, профили CSV и Excel, дубли, ошибки чтения и границы
проверки сохраняет `pipeline.synthetic_audit`. Каталог не означает новой
смысловой сверки всех первичных PDF, HTML, DOC и вложенных архивов.

## Этап 3. Методы и зафиксированные правила

Для рядов не короче 24 последовательных месяцев:

1. `iid_increment_bootstrap`: последний уровень + накопленная сумма
   центрированных месячных приращений из последних 24 приращений.
2. `block_increment_bootstrap`: тот же механизм, но приращения выбираются
   неперекрывающимся выходным потоком блоков длины 3 из перекрывающихся
   последовательных исторических блоков; швы блоков не являются наблюдениями.
3. `seasonal_residual_bootstrap`: повтор последнего годового профиля с
   центрированными ошибками сезонного naive из последних 24 доступных ошибок.

Все значения ограничиваются снизу нулём; частота срабатывания ограничения
публикуется. Такое ограничение может смещать среднее и создавать массу в нуле.
Генераторы не восстанавливают ненаблюдаемый спрос и не задают мощность.
Гиперпараметры фиксированы до расчёта метрик: seed 42, 200 реализаций,
горизонты проверки 1 и 3 месяца, выходной горизонт 12 месяцев.
Для коротких рядов — `template_scale`, одна траектория на сценарий:
последний годовой уровень либо единственный месячный профиль. Годовой горизонт
2024–2030 — чувствительность, а не достоверный прогноз до 2030.

Сценарии `reference`, `scale_down`, `scale_up`: множители 1, 0.9, 1.1.
±10% — открытые исследовательские параметры, а не оценённый эффект действия.
Парные сценарии используют одинаковые случайные реализации. Их нельзя
приписывать резервному/постоянному парому, CAPEX или OPEX без решения команды.

Проверка идёт последовательно: последние 6 месяцев ряда — отчётное окно,
предшествующие до 12 месяцев — выбор метода, обучение строго раньше цели.
Нужно минимум 24 месяца обучения. При наличии `available_by` будущие
публикации маскируются; последняя обучающая точка может отставать от даты
выдачи, горизонт учитывает этот разрыв. Без исторической доступности — только
ретроспективная проверка по окончательному снимку, без заявления as-of качества.
2026 год каботажа не участвует ни в выборе, ни в проверке генераторов.
Уже исследованные окна 2025 не называются новой независимой слепой проверкой.

Метрики: MAE, WAPE, CRPS, покрытие и ширина центрального эмпирического 80%
диапазона, Winkler score; детерминированные naive и seasonal_naive — baseline.
Метод выбирается по CRPS на окне выбора, отчётное окно выбор не меняет.
Окна и количество доступных проверок сохраняются. Нехватка данных —
`not_evaluated`, а не нулевая ошибка. Прогностическая полезность оценивается
относительно реальных/estimated отложенных целей, не собственной синтетики.

## Этапы 4–8. Выход и интеграция

Код — отдельные `pipeline.synthetic_*` и `backend.synthetic_*`, без правок ML.
Результаты — отдельный игнорируемый Git каталог `reports/generated/synthetic/`:
каталог рядов, синтетические CSV/JSON, реальные reference-строки отдельно,
происхождение, метрики, диагностика, отчёт, SHA-256 и параметры запуска.
FastAPI загружает комплект только по явно заданному серверному
`BB_SYNTHETIC_BUNDLE_PATH`; по умолчанию функция недоступна.
Фильтры, реализации, сводки, сравнение, происхождение и экспорт — отдельные
маршруты `/synthetic/*`. Реальные таблицы, ML-артефакты и рабочий прогноз не меняются.

Для экспериментального ML-обучения готовой рекомендации нет: отдельный
эксперимент с обучением только внутри временного среза и внешней реальной целью
потребует согласования. Никакое увеличение точности заранее не утверждается.

Методическое основание: [bootstrap временных рядов](https://otexts.com/fpp3/advanced.html),
[временная проверка и оценка распределений](https://otexts.com/fpp3/toolbox.html).
Используются принципы этих методов; STL, bagged ETS и их доказанные на иных
данных эффекты этому конвейеру не приписываются.
