# Единый интерфейс FloCast

Дата: 11 ноября 2026 года. Изменения выполнены локально, без commit и push.
Существующие незакоммиченные изменения сохранены.

## Причина разных страниц

FastAPI явно возвращал `frontend/capacity.html` на `/` и `/capacity`.
React/Vite был отдельным приложением с базой `/dashboard/`; production-сборка
раздавалась только на `/dashboard/`. Это были разные точки входа, а не две темы.

## Результат

Единственный основной интерфейс — существующий React из `frontend/src/App.tsx`.
Палитра, боковая панель, карточки, графики, темы и помощник сохранены.
Калькулятор встроен в этот же интерфейс и оформлен его CSS-переменными.
Формулы `backend.scenarios.capacity_balance`, ML и существующие API не изменены.
Результаты прогноза и сценарного расчёта не подменяются примерами.

| Адрес | Назначение |
|---|---|
| `http://127.0.0.1:5173/` | Разработка через Vite; Backend работает отдельно на 8000 |
| `http://127.0.0.1:8000/` | Демонстрация: FastAPI раздаёт актуальную React-сборку и API |
| `http://127.0.0.1:8000/#capacity` | Калькулятор внутри React |
| `/dashboard/` | Перенаправление на `/` |
| `/capacity`, `/capacity/`, `/capacity.html` | Перенаправление на `/#capacity` |
| `/docs` | Сохранённая документация API |

Порядок запуска и подготовка зависимостей описаны в корневом `README.md`.
Для разработки: `python -m uvicorn backend.app:app --reload` и во втором терминале
`npm --prefix frontend run dev -- --host 127.0.0.1`.
Для демонстрации: `npm --prefix frontend run build`, затем
`python -m uvicorn backend.app:app --host 127.0.0.1 --port 8000`.

Раздача SPA выполняется после регистрации API. Неизвестные API возвращают 404,
неверный метод известного API — 405, ошибочные значения — 422. Отсутствующие
ресурсы и исходники не превращаются в HTML. Сборка содержит SHA-256 исходников,
настроек и public-ресурсов; Backend не отдаёт устаревшую сборку и возвращает 503
с командой сборки. API работает и без UI. Пересборка не требует перезапуска Backend.
HTML и настройки выдаются без кэширования. Предусмотрено снятие старого PWA scope
`/dashboard/` и старого production service worker при запуске Vite.

## Проверки

- Backend: 65 тестов прошли. Проверены прежние API и расчёты, перенаправления,
  SPA fallback, 404/405, custom API prefix, отсутствие/повреждение/устаревание
  сборки и её появление без перезапуска сервера. Ruff check и format check прошли.
- Frontend: lint прошёл; 8 тестов прошли, включая отдельный запуск с настоящим
  сохранённым ответом API для проверки CSV. Обычный `npm test` без этой переменной
  штатно пропускает проверку реального артефакта.
- Production: TypeScript и Vite build прошли. Последовательная итоговая сборка
  выполнена с лимитом памяти Node 512 МБ после нехватки памяти при параллельной
  проверке. SHA-256 сборки совпадают с текущими исходниками.
- Браузер: на Backend открывается React, работают все семь пунктов навигации,
  оба направления, три SVG-графика и переключение светлой/тёмной темы.
- Калькулятор на Backend: `120 / 100 / +10`, `2027-01` даёт дефицит 20 → 10 т.
  Изменение ввода скрывает старый результат; `2027-13` показывает ошибку API.
- Vite проверен отдельно на временном порту 5174, чтобы исключить прежний PWA-кэш
  на 5173. React и прогноз совпадают с production. Через proxy калькулятор
  `100 / 80 / +40`, `2027` даёт дефицит 20 → 0 т и запас 20 т.
  Постоянная настройка порта осталась 5173.
- CSV скачан кнопкой в браузере; все семь периодов, значения и версия модели
  совпадают с реальным ответом API. Тестовые числа используются только во вводе
  сценарного калькулятора и не подменяют прогноз.

## Ограничения и оставшаяся работа

Внешний SDK Yandex загружается, однако iframe чата в проверочном браузере
показывает отказ соединения. Статус SDK «подключён» не доказывает готовность
диалога. Нужна отдельная проверка ограничений встраивания/настроек канала;
прогноз и калькулятор от этой проблемы не зависят.

Существующая `.venv` не импортирует `pydantic_core.ArgsKwargs`. Проверки и рабочий
Backend выполнены системным Python 3.13 с установленными зависимостями.
Перед использованием этой `.venv` необходимо восстановить её зависимости;
окружение в рамках архитектурных правок не переустанавливалось.

Vite предупреждает о JS-бандле около 695 КБ до gzip. Разделение бандла можно
выполнить отдельной задачей. Ограничения источников и методологическая приёмка
моделей сохраняются; численные эффекты транспортных действий не утверждались.

ИИ выполнил правки кода, документации, автоматические и браузерные проверки.
Человеческая приёмка интерфейса и предметная проверка данных командой остаются
отдельными шагами; их выполнение этим отчётом не заявляется.
