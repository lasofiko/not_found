# Регистрация источников из for-misha

12 ноября 2026 года зарегистрирован `for-misha-2026-11-12.zip` по его README.
Это отдельный исследовательский комплект. Исходные реестр, манифест сборки,
ML-входы, модели и HTTP API не изменены; публичных полей API не добавлено.

## Базовая регистрация

В локальном `data/raw/research_package/` сохранены исходный ZIP и 25 вложений
с SHA-256. В `data/processed/research_package/` создан версионированный каталог;
`latest.json` указывает текущую регистрацию. Внутри него:

- `source_registry.json` — 26 паспортов файлов с местом получения и хешами;
- `source_references.csv` — ссылки из строк и связи с доступными оригиналами;
- `tables/` — семь таблиц, все 302 строки и исходные поля сохранены;
- `table_catalog.csv`, `row_issues.csv`, `quality_report.json`, `README.md` —
  состав, ограничения и статус проверки;
- `manifest.json` — хеши кода, исходного ZIP и выходов регистрации.

| Статус использования | Строк | Значение |
|---|---:|---|
| `research_context` | 229 | Контекст исследования, без принятия в обучение |
| `duplicate_reference` | 32 | 30 строк AB о вагонах/накатной технике и 2 годовых дубля Росморпорта |
| `planned` | 26 | Выборка плановых переходов и стоянок |
| `missing_primary_hold` | 14 | C029–C041 и C050: отсутствующие оригиналы из личного хранилища |
| `conflict_hold` | 1 | Заявление о более 1,5 млн т, расходящееся с таблицей Росморпорта |

Поля `opened_source`, `search_snippet`, `user_provided_text` сохранены как
заявленные в исходных строках. В блоке F 23 строки имеют `user_provided_text`;
общее описание README не повышает их до `opened_source`.
Все зарегистрированные строки имеют `evidence_status: provided_unverified`,
`review_status: pending`. Сообщение README о сверке AB Петей сохранено отдельно;
оно не превращено в завершённый построчный журнал человеческой проверки.

## Ограничения и недостающие материалы

Для всех 41 строк Telegram найдено сообщение с указанным ID в сохранённой
выгрузке. Для 26 строк расписаний найдены соответствующие изображения.
Это проверка связи с оригиналом; числа и время заново не переизвлечены.
Часть PDF связана с тарифными строками по описанию пакета; числовые ячейки
ещё требуют сверки. Остальные ссылки зарегистрированы с явным отсутствием
связанной локальной копии. Сеть при регистрации не использовалась.

Нужно получить у Пети оригиналы протоколов для C029–C041, снимок для C050
и исходный файл расписания на ноябрь 2026 — февраль 2027.
Около 20 других версий расписаний из первой выгрузки не разобраны:
предоставленная выборка 2025 года остаётся выборкой планов.
Отсутствие сводок оператора за 2026 год записано как сообщение README пакета,
а не результат нового поиска. Заявленное совпадение массы с существующим
`supplemental_freight.csv` здесь повторно не проверялось.

Единицы сохранены без пересчёта: регистрация не нормализует погрузку КЖД,
не переводит вагоны/TEU/автомобили в тонны, не делит `both` на направления.
Годовые значения Росморпорта не склеиваются с направленной линией;
субсидируемая масса всей программы не приписывается одной линии.
Принятие в целевой ряд и устранение расхождений остаются решениями команды.

## Воспроизведение и проверка

Из корня проекта в активном Python-окружении:

```bash
python -m pipeline.research_package --archive for-misha-2026-11-12.zip
python -m pipeline.research_package --verify
python -m pytest -q tests/test_research_package.py
python -m ruff check pipeline/research_package.py tests/test_research_package.py
```

Новых зависимостей нет. Повтор с теми же байтами и кодом проверяет существующую
версию и сохраняет дату первоначальной регистрации. Изменение пакета или кода
создаёт другую версию, прежняя сохраняется. `--verify` проверяет хеши оригиналов,
кода и выходов, повторно собирает строки и связи из ZIP и сверяет их с CSV.

Выполнены регистрация и полная проверка реального пакета, повторный запуск
с проверкой неизменности паспортов, четыре теста и Ruff. Тесты проверяют
сохранение исходных ограничений, неприкосновенность основного манифеста,
отклонение небезопасного ZIP до записи, обнаружение повреждённого оригинала
и подмены пустого значения нулём даже при обновлённом хеше выходного CSV.

ИИ подготовил `pipeline/research_package.py`, тесты, регистрацию и эту
инструкцию; обновлены `README.md`, `data/README.md`, `docs/contracts.md`.
Новая человеческая приёмка результата не зафиксирована. Машинная проверка
не заменяет предметную сверку источников человеком.
