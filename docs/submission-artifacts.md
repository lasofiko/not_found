## 2. Обозначения готовности

- **В репозитории** — файл найден в проверенной версии `main`; работоспособность этим отдельно не доказывается.
- **В архиве** — содержимое найдено в одном из переданных ZIP; результат относится к указанному экспортному снимку.
- **По отчёту** — результат описан участником, но соответствующий оригинал в полученных материалах отсутствует.
- **Требует приёмки** — остаётся предметная, техническая или командная проверка, названная в ограничениях.

Статус артефакта отличается от статуса числа. `observed` означает опубликованный показатель с определённым охватом, `estimated` — расчётную оценку, `synthetic` — вымышленный пример. Прогноз (`forecast`) и сценарный расчёт (`scenario`) учитываются отдельно. Наличие любого из этих статусов не подтверждает готовность всего продукта.
