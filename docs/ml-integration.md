## Контракт прогноза

GET /api/v1/forecasts принимает region=kaliningrad, direction=inbound или outbound,
mode=sea, end_year от 2024 до 2030. Возвращает JSON ForecastResponse.

| HTTP | status | Смысл |
|---|---|---|
| 200 | ready | Артефакт проверен, result_type=forecast, predictions содержит весь запрошенный годовой диапазон. |
| 404 | not_available | Регион, направление или вид не поддержаны. |
| 503 | not_connected | Указатель или файл модели отсутствует. |
| 500 | error | Нарушена целостность, схема, протокол или чтение комплекта. |
| 422 | стандартный error | Неверный год или тип параметра. |

В успешном ответе есть target_name, geography, direction, mode, unit,
training_period, forecast_origin, observations, predictions с интервалами 80/95,
provenance, data_version, model_version, selected_model, metrics и warnings.
Метрики содержат selected и baseline с development/holdout, MAE, WAPE и размером
выборки. Окна выбора 2020–2021, проверки 2022–2023, горизонт проверки один год.

ForecastService читает снимок указателя, закрепляет путь модели и проверяет SHA
до и после получения прогноза. Используется существующий ml.predict.forecast
без обучения и изменения математической логики. Status и config зависят от
проверенной доступности. Наличие модели не означает наличие исходных таблиц
или готовность численного сценарного анализа.

React обращается к backend, проверяет схему Zod, типы чисел, календарь и срез.
Запросы имеют таймаут 10 секунд. Смена параметров отменяет старый запрос и
снимает старый результат. CSV содержит каждый полученный период, исходное число,
единицу, географию, направление, статус, версии, источники и интервалы.
На экране числа форматируются для чтения, CSV сохраняет полную точность.

## Запуск локальной демонстрации

Из корня проекта с активным окружением существующего проекта.

~~~powershell
python -m pip install -e ".[dev]"
npm --prefix frontend ci --ignore-scripts
npm --prefix frontend run build
python -m uvicorn backend.app:app --host 127.0.0.1 --port 8000
~~~

Открыть http://127.0.0.1:8000/dashboard/. Выбрать направление и конечный год,
сверить источник и версии, скачать CSV. В разделе сценариев выбрать А или Б,
прочитать доступность и открыть калькулятор. Контроль 120/100/+10 за один период
даёт дефициты 20 и 10 т и сокращение 10 т. Открытие помощника загружает SDK отдельно.
При недоступности SDK появляется сообщение и повторная попытка. Контекст модели
в сервис не передаётся автоматически.

Для разработки запустить backend той же командой, затем npm --prefix frontend run dev.
Vite на 5173 проксирует /api, /config.json, /capacity и /app.js к localhost:8000.
При изменённом BB_API_PREFIX список прокси Vite нужно согласовать с префиксом.
Совместный запуск получает префикс автоматически через config.json.

Для чистой копии из eee.zip нужны папка ddd/models/bb-ml-6237c3f27262
и ddd/models/latest.json. Сохраняйте относительные пути внутри models.
Для интеграционных тестов сравнения с исходным экспортом также нужны
ddd/reports/generated/ml/bb-ml-6237c3f27262/forecast.json и run_manifest.json.
Эти файлы остаются локальными. Сама копия кода без них запускает API и
показывает not_connected. Артефакты не включаются в Git.

## Проверки и ограничения окружения

~~~powershell
python -m pytest backend/tests -q
python -m ruff check backend
python -m ruff format --check backend
npm --prefix frontend test
npm --prefix frontend run lint
npm --prefix frontend run build
~~~

frontend/tests/api.test.mjs использует NF_FORECAST_FIXTURE для сравнения с
реальным ответом API. При отсутствии файла пропускается только этот
интеграционный случай, проверки отказов исполняются. Старые синтетические
фикстуры сохранены для прежних тестов, действующий экран их не использует.

В среде проверки Python 3.13.2, Node 24.14.0, statsmodels 0.14.6 при требовании
0.15.x в pyproject. Новый HTTP-путь не вызывает statsmodels и не переобучает модель.
Для нового обучения требуется установить объявленные ML-зависимости. Отсутствующий
xlrd и права Windows на symlink ограничивают полный прогон ETL-тестов.
Эти проверки не ослаблялись.

Команда запуска использует loopback. Публичное сетевое размещение на Windows
требует исправления ранее выявленной конфигурации Starlette/StaticFiles.
Во время данной работы публичный сервис не запускался.

ИИ выполнил интеграцию и автоматические проверки. Человек предоставил модель
и задал определения действий. Предметная приёмка исходных ячеек, параметров судна
и экономического эффекта остаётся за командой.
