# Текущая архитектура

Backend: фабрика FastAPI `backend/app.py`, настройки `BB_*`, общие ошибки,
маршруты health/config/status и сценарный расчёт мощности. API не требует
данных или ML. Калькулятор мощности (`frontend/capacity.html`, `app.js`)
раздаётся на `/` и `/capacity`, читает фактический префикс из `/config.json`.

React + TypeScript + Vite собираются в `frontend/dist`, раздаются backend
на `/dashboard/`. Без сборки доступен калькулятор, демо возвращает 503 с
инструкцией. При разработке Vite слушает 5173, страница — `/dashboard/`.
Статические синтетические примеры выбираются по направлению и гипотезе.
Они не используют API прогноза; наблюдения и обученная модель не подключены.
Неутверждённые эффекты не рассчитываются. Сохранена панель Yandex AI Studio из нового дизайна; чат использует внешний сервис.

`pipeline/` отвечает за оригиналы, реестр, ETL и качество; `ml/` — за будущие
модели. Реальные данные не требуются для API и тестов. Цель, два основных
действия и их параметры остаются решениями команды.

ИИ подготовил локальные исправления и проверки. Человеческая предметная
приёмка данных, коэффициентов и решений команды ещё не выполнена.
