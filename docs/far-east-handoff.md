# Камчатка и Приморье: передача ML-инженеру

Отдельный комплект из `данные камчатка + дальний востокъ (2).zip`.
Чукотка и остальные территории исключены из итоговых данных, включая смешанные
книги. Неизменённый исходный ZIP сохраняется целиком. Калининградский комплект
и модели не переписываются. Целевой ряд для новых регионов пока не утверждён.

Получено 648 CSV листов и 337 085 отобранных Excel-строк. Объединённый
грузовой набор содержит 526 записей, годовая матрица — 48 строк «регион × год».
Отдельно подготовлены 666 998 записей веса/стоимости внешней торговли
и 22 154 региональные записи (включая транспортный контекст: эти наборы
пересекаются и не складываются). Источники и качество указаны построчно.
Из ZIP исключено 193 вложения по имени Чукотки; дополнительные анонимные
формы и строки других территорий исключены по содержимому.

## Файлы

Все результаты находятся в `data/processed/far_east/`:

| Файл | Назначение |
|---|---|
| `transport_long.csv` | Основной объединённый грузовой набор: показатель за период с единицей и происхождением |
| `freight_annual_panel.csv` | Удобная годовая матрица: регион × год, отдельно автомобильные тонны, автомобильные т·км и железнодорожные отправления |
| `series_coverage.csv` | Ряды, частоты, диапазоны, пропуски; начинайте выбор данных здесь |
| `regional_indicators.csv` | Транспортный, пассажирский и экономический контекст двух регионов |
| `customs_long.csv` | Вес и стоимость распознанных таможенных форм; итоги и подгруппы раздельно |
| `table_rows.csv` | Общая структурная конверсия отобранных Excel-строк |
| `tables/*.csv` | Каждый отобранный лист отдельно с исходными заголовками и номерами строк |
| `table_catalog.csv` | Карта листов, путей CSV, распознавания и причин исключения |
| `archive_inventory.csv` | Все вложения ZIP, SHA-256, исключения и повторы |
| `source_registry.json` | Паспорта оригиналов и связи с ZIP/RAR |

CSV: UTF-8 с BOM, запятая, десятичная точка. Пустое поле не равно нулю.
Коды товаров читайте как строки с сохранением начальных нулей.
`table_rows.csv` не является матрицей обучения: смысл `column_001` и других
колонок зависит от конкретного листа. Статус `csv_only_review_required`
означает структурную конверсию без автоматического толкования всех показателей.

## Возможные ряды для ML

Предоставленный CSV содержит годовые транспортные показатели 2001–2024:
автомобильные перевозки и грузооборот обоих регионов, железнодорожные отправления
Приморья. Фактическая длина каждого ряда указана в `series_coverage.csv`.
`freight_annual_panel.csv` разворачивает только предоставленную выборку без
добавления значений из RAR. Источник/издание/ячейка указаны для каждого
показателя. История 2001–2022 и точки 2023/2024 взяты из разных изданий:
согласование методики остаётся открытым. Отсутствующие железнодорожные
показатели остаются пустыми, а не нулями.
В RAR есть самостоятельная региональная коллекция с более ранними изданиями
и экономическими показателями; её нельзя автоматически склеивать с новой выборкой.

Данные аэропортов — месяцы 2021 года для Елизово и Владивостока. Одного
сезонного цикла недостаточно для убедительной проверки сезонной модели.
Морской Excel содержит **грузооборот в т·км нарастающим итогом**, а не массу
месячных отправок. Разности накоплений в этой подготовке не создаются.

Первым вариантом для обсуждения являются годовые автомобильные перевозки
отдельно по регионам: более длинная история в понятной единице. Второй вариант —
железнодорожные отправления Приморья с отдельным определением. Команда должна
выбрать показатель и политику перехода между изданиями. Региональный показатель
не доказывает перевозки между конкретными территориями России.

Пример загрузки (pandas — необязательная зависимость группы `notebooks`):

```python
import pandas as pd

base = "data/processed/far_east/"
coverage = pd.read_csv(base + "series_coverage.csv")
print(coverage.to_string(index=False))
data = pd.read_csv(base + "transport_long.csv", dtype=str, keep_default_na=False)
candidate = data[
    (data.region == "kamchatka")
    & (data.metric == "freight_mass")
    & (data.unit == "tonnes")
    & (data.period_basis == "annual")
    & data.source_title.str.startswith("Регионы России.")
]
print(candidate[["series_id", "period", "value", "source_title", "quality_flags"]])
```

Издание входит в `series_id`. Выберите один ряд либо явно согласуйте переход
изданий. Нельзя делать `groupby(region, period).sum()` по всему набору:
так смешаются тонны, т·км, виды, издания и повторяющиеся наблюдения.
Проверьте уникальность периода; начните с naive/drift, делите историю по времени,
отдельно оцените периоды после 2022 года. Обучение здесь не выполнялось.

## Правила обработки

1. ZIP проверяется по CRC; оригиналы сохраняются без изменений с SHA-256.
   Повторные байты разбираются один раз; все пути остаются в реестре.
2. География определяется внутри таблицы: колонка `REGION` или явное имя
   территории. Для старых однорегиональных форм используется заголовок/имя файла.
   Неустановленная география не включается в результаты.
3. `Камчатская область` и `Камчатский край` сохраняются в `original_geography`.
   История до 2007 года и старые территории помечены: сопоставимость границ
   требует человеческой проверки, механическая склейка не выполняется.
4. Миллионы тонн → тонны; миллионы/тысячи т·км → т·км; тыс. USD → USD.
   Прочие единицы сохраняются. Доллары не превращаются в рубли; штуки, вагоны,
   TEU и дополнительные товарные единицы не переводятся в тонны.
5. Специальные коды остаются в `original_value`, нормализованное поле пусто
   и снабжено флагом. Пропуски не заполняются, опубликованные нули сохраняются.
   Годовые данные не распределяются по месяцам.
   В частности, все 22 железнодорожных значения Камчатки в RAR имеют код
   `-88888888.0`: числовые значения оставлены пустыми. В приложенном паспорте
   расшифровка кода не найдена; это не наблюдённый железнодорожный ряд.
6. В таможенных формах автоматически распознаются явно подписанные машинные
   колонки `TONN`/`TDOLL` с определимым периодом. Остальные формы конвертируются
   в CSV для дальнейшего разбора. Любой числовой столбец нельзя считать массой.
7. Экспорт/импорт — внешняя торговля, не `inbound/outbound` внутренних перевозок.
   Товарные итоги, вложенные коды, группы стран и отдельные страны пересекаются.
   Кварталы, накопления и годовые итоги не складываются вместе.
8. `observed` означает число в предоставленной таблице; везде сохраняются
   `evidence_status=provided_unverified`, `review_status=pending`. Первичные
   публикации и даты доступности не сверены человеком; `available_at` пусто.
   Контекст нельзя автоматически использовать как признаки с нулевым лагом.

Методологические комментарии сохранены точно: они могут перечислять другие
территории, но не являются наблюдениями этих территорий. DOC/PDF сохранены
как справочные материалы; инструкции из них не исполняются. Упомянутый
`хак.docx` в рабочей папке не найден и не использован.

## Воспроизведение

Python 3.11+, `xlrd==2.0.2`, `libarchive-c==5.3` и системная libarchive
с поддержкой RAR. В текущем Linux доступна `libarchive.so.13`;
имя пакета/способ установки на другой системе нужно проверить отдельно.
Для XLSX внешняя библиотека не требуется.

```bash
python -m pip install -e ".[data]"
python -m pipeline.far_east --archive "данные камчатка + дальний востокъ (2).zip"
python -m pipeline.far_east --verify
python -m unittest tests.test_far_east -v
python -m pipeline.far_east --package
```

После установки зависимостей сборка работает без сети и внешних папок.
Архив `reports/generated/far-east-ml-handoff-<версия>.zip` и соседний SHA-256
содержат CSV, инструкцию, код и оригинальный ZIP. Передача остаётся локальной.
Индивидуальные оригиналы, уже находящиеся в ZIP/RAR, повторно не упакованы.
В новой папке CSV можно читать сразу; для полной проверки сначала восстановите
рабочие оригиналы из сохранённого ZIP:

```bash
python -m pip install -e ".[data]"
python -m pipeline.far_east --archive data/raw/far_east/<archive_sha256>.zip
python -m pipeline.far_east --verify
```

`archive_sha256` указан в `manifest.json`. Для этого комплекта используется
`pipeline.far_east --package`; существующий `pipeline.package` относится к Калининграду.

`--verify` сверяет хеши, территории, единицы, периоды, покрытие и **каждую
нормализованную исходную ячейку** с сохранённым XLS/XLSX/CSV. Это техническая
сверка с предоставленным файлом, не подтверждение первичной публикации.

## Приёмка

ИИ подготовил ETL, конверсию, описание и автоматическую проверку. Человеческая
предметная приёмка **не зафиксирована**. Нужно сверить выбранную цель с первичной
публикацией, согласовать границы Камчатки, переход изданий, временные срезы
и лаги факторов. Если нужны дополнительные таможенные признаки, формы
`csv_only_review_required` требуют отдельного семантического разбора.
