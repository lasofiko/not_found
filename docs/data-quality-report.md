## Воспроизведение

Манифест фиксирует каждый вход и выход, код и журнал проверки. `pipeline.verify` проверяет хеши, единицы и повторно сверяет целевые ячейки с оригиналом. Пакет пересобирается без сети из включённых оригиналов; режим и отсутствующие source_id указаны в манифесте. Результат автоматической проверки распакованной копии фиксируется отдельно в отчёте проверки передачи; независимая пересборка другим участником ожидается.
